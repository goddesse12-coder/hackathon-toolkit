# 계획과 진행 기록

문제에서 필수 결과물과 평가 조건을 추출하고, 각 조건을 어떤 산출물과 검증으로 충족할지 연결한다. 입력 파일을 먼저 목록화하고 핵심 파일부터 읽는다. 계획을 확정하기 전에 가장 위험한 가정 하나를 작은 실행으로 확인한다.

작업 경로에 [계획 양식](../../templates/task-plan.md)과 [진행 양식](../../templates/progress.md)을 필요한 경우 복사한다. 제목만 채우는 대신 다음 실행, 막힌 이유, 완료를 입증하는 결과를 기록한다. 기록 자체가 과제의 제출 형식을 바꾸지 않는다.

작업을 필수·선택으로 나누고 검증·제출 시간을 남긴다. 전체 시간의 10/60/20/10%를 파악/수행/검증/제출의 시작점으로 사용할 수 있지만 문제 성격에 맞게 조정한다. 병렬 작업은 플랫폼과 사용자 범위가 허용하고 작업 경로가 충돌하지 않을 때만 고려한다.

중요한 선택은 [의사결정 양식](../../templates/decisions.md)에 비교한 대안, 선택 이유, 실제 근거를 짧게 남긴다. 단계가 끝났거나 접근을 바꿨을 때 진행 기록을 갱신한다. 새 대화에서는 이미 완료된 단계를 반복하지 말고 기록과 실제 파일이 일치하는지 확인하고 재개한다.
