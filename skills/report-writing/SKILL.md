# 보고서 작성

누가 어떤 결정을 내려야 하는지, 제출 형식과 분량이 무엇인지 먼저 확인한다. 지정 양식을 우선한다. 별도 양식이 없으면 문제·핵심 결론·근거·실행안·한계 순서로 작성하되 과제에 맞게 조정한다.

각 제안은 이를 지지하는 근거, 예상 효과, 필요한 조건을 연결한다. 계산한 효과와 검증되지 않은 기대효과를 구분한다. 대안 선택이 중요한 과제라면 같은 판단 기준으로 비교하고 선택 이유를 밝힌다.

결론마다 [출처 기록](../../templates/sources.csv)과 연결한다. 추정 수치에는 산식·가정·민감한 변수를 표시한다. 원문에 없는 수치나 인용문을 만들지 않는다. 상세 계산은 본문을 방해하지 않는 위치에 두되 재현 가능하게 남긴다.

최종 문서만 보는 독자가 문제, 근거, 선택 이유, 다음 행동을 이해하는지 확인한다. 파일 변환 후 표 잘림·글자 누락·페이지 넘침·링크·파일 열림을 실제로 확인한다. 렌더링 도구가 없으면 확인한 범위와 미확인 범위를 구분한다. 일반 Markdown 초안을 만든 것을 Word·PDF 완성으로 보고하지 않는다.
