# 원인에 근거한 오류 수정

실제 오류 메시지, 입력, 실행 명령, 환경과 기대 동작을 확보한다. 재현이 안 되면 조건을 좁히고 재현 불가 상태를 명시한다. 오류 문구와 관계없는 코드를 한꺼번에 수정하지 않는다.

실패 지점까지 입력과 중간 값을 추적하고 가능성이 높은 원인부터 검사한다. 한 번의 변경으로 어떤 가설을 확인하려는지 적는다. 수정 전의 실패와 수정 후의 결과를 같은 조건에서 비교한다.

핵심 재현 사례와 영향 받는 정상·경계 사례를 실행한다. 새 결과가 원인 가설을 반박하면 가설을 바꾼다. 두 차례 같은 실패가 반복되면 로그·입력·환경에서 새 증거를 얻기 전까지 같은 시도를 반복하지 않는다.

최종 기록에는 원인, 변경 범위, 실행한 검증, 남은 위험을 포함한다. 테스트를 실행할 수 없었다면 정적 검토와 실행 검증을 구분한다. 테스트 통과를 위해 요구사항이나 판정 기준을 조용히 약화시키지 않는다.
