# 데이터 분석

먼저 열 이름·타입 후보·행 수·결측·중복·기간·단위를 확인한다. CSV의 빠른 점검에는 [csv_profile.py](../../tools/csv_profile.py)를 사용한다. 이 도구는 빈 문자열과 공백만 결측으로 세며 NA·NULL 같은 표시는 자동 결측 처리하지 않는다. 기본 100,000행까지만 읽는다. 제한에 도달했는지 출력에서 확인한다.

식별자와 우편번호는 숫자로 보이더라도 임의로 수치형으로 바꾸지 않는다. 도구의 숫자 통계는 값이 숫자로 해석되는지 확인하는 참고용이다. 통화 기호·천 단위 구분자는 자동 제거하지 않는다. 원본을 유지하고 전처리 판단과 제외 행 수를 기록한다.

계산 전에 지표의 분자·분모·집계 단위·중복 처리·기간 경계를 정의한다. 평균의 평균과 가중 평균, 건수와 고유 대상 수를 구분한다. 조인은 키 유일성과 조인 전후 행 수를 확인해 중복 증식을 찾는다. 시간 데이터는 미래 정보가 과거 판단에 섞이지 않도록 분리한다.

집계 결과를 전체 합계, 극단값, 작은 표본 재계산으로 교차 확인한다. 빈 데이터·0인 분모·누락 범주에서의 처리 방법을 명시한다. 차트에는 단위·축·기간·표본 수를 표시한다. 상관관계만으로 원인이라고 결론내리지 않는다.

원본 경로, 사용 열, 전처리, 계산식, 결과, 검산과 한계를 남긴다. 필요한 경우 [외부 도구 목록](../../references/EXTERNAL_TOOLS.md)의 DuckDB를 검토하되 설치 가능 여부를 먼저 확인한다.
