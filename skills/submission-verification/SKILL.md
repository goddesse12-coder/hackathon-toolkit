# 제출 검증

원래 문제에서 요구사항을 다시 읽고 각 항목을 실제 파일·절·기능·계산 결과와 연결한다. [검증 양식](../../templates/verification.md)을 사용할 수 있다.

- 코드: 핵심 동작과 중요한 실패·경계 입력을 실행한다.
- 분석: 행 수·조인 결과·합계·분모·단위를 확인하고 핵심 지표를 별도로 검산한다.
- 문서: 지정 형식으로 파일이 열리는지, 주요 표·페이지·글자가 온전한지 확인한다.
- 웹: 실제 주요 사용자 흐름과 오류 상태를 점검한다. 화면이 보이는 것과 기능이 동작하는 것을 구분한다.

[file_manifest.py](../../tools/file_manifest.py)로 필수 파일 존재·빈 파일·해시를 확인할 수 있다. 이 도구는 정답, 문서 내부, 시각 품질, 개인정보 포함 여부를 검증하지 않는다. manifest 출력은 검사 대상 폴더 밖에 저장한다.

검증 기록은 통과·실패·미검증으로 구분하고 실행 명령 또는 확인 방법과 실제 결과를 포함한다. 마지막 변경 이후 영향을 받는 확인을 다시 실행한다. 제한 시간 안에 해결할 수 없는 실패는 숨기지 말고 제출 가능한 범위와 한계를 정리한다. 제출·업로드는 플랫폼 안내와 사용자가 허용한 범위에서 수행한다.
